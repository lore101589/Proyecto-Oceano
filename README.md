# El Pez Hambriento

Es un juego desarrollado en Python utilizando la librería **Pygame**. 
El objetivo del juego es controlar a un pez que debe alimentarse de gusanos, evitar a los cangrejos y sobrevivir en el océano. Para avanzar de nivel, quien juega debe comer 10 gusanos en un máximo de 30 segundos.

## ¿Cómo se juega?

* **Movimiento:** Utilizar las teclas **W**, **A**, **S**, **D** o las **flechas** del teclado.
* **Objetivo:** Comer 10 gusanos en 30 segundos para avanzar de nivel.
* **Obstáculos:** Evitar el contacto con los cangrejos.
* **Vidas:** Se pierde una vida al tocar un cangrejo o al no alcanzar el objetivo dentro del tiempo establecido.
* **Reiniciar:** Presionar la tecla **R**.
* **Salir:** Presionar la tecla **ESC**.

## Cómo ejecutar el juego

1. Tener **Python** instalado.
2. Instalar **Pygame** ejecutando el siguiente comando en la terminal:
```bash
pip install pygame
```

## Música y efectos de sonido

El juego incluye música de fondo y efectos de sonido que acompañan los distintos eventos durante la partida (todos los archivos fueron obtenidos de la plataforma **Freesound.org**):
* `sound_background.wav`: Música de fondo del juego.
* `sound_eat1.wav`: Efecto de sonido al comer un gusano.
* `loselife.wav`: Efecto de sonido al perder una vida ("Gata Only").
* `sounds_game_over.wav`: Efecto de sonido al finalizar la partida.
